# Contributing

Issues and pull requests are welcome. Please keep changes focused and describe the user-visible behavior they affect.

Before submitting:

1. Build with `zsh build.sh` on macOS.
2. Confirm that pending time remains local until the user adds it to records.
3. Avoid adding personal data, private service URLs, credentials, browsing history, or lesson recordings.
4. Explain any macOS permission or signing changes in the pull request.

Do not include real study records, Keychain exports, or private recordings in test fixtures.
